# Managed local meeting speech setup

Continue the approved local-recording plan. Replace the normal engine/model file chooser with an in-app setup dialog. Bundle a pinned whisper-rs/whisper.cpp CPU runtime into the desktop; users download only the pinned multilingual base weights (147,951,465 bytes, SHA-256 from the existing verified prototype setup). macOS and Windows use the same inference API. No arbitrary runtime executable is downloaded. Preserve the existing trusted external-engine chooser as an advanced option.

Ruling: CPU is the initial portable baseline; GPU qualification remains future work. Model download is explicitly initiated, shows byte progress and verification, supports cancel/retry, rejects incorrect size/hash, and publishes only a verified complete file. No renderer-provided URL/path/manifest. Model artifacts are shared device resources, without meeting text/audio/account tokens. Download cancellation is independent of recording, and signing out cancels an active download. Status must not enable transcription until verification completes.

Run managed inference in a disposable child of the desktop executable, before Tauri startup. Parent EOF terminates that child, cancellation is bounded by the existing supervisor. Process WAVs in bounded chunks, keep source-relative timestamps, and disable transcript/debug printing. No network or cloud fallback in inference. Verify installed weights before use. The developer CLI retains external whisper-cli support.

Steps: (1) verified artifact installer and failure/cancellation/locking tests; (2) bundled runtime and supervised worker, public-sample offline smoke; (3) authenticated native setup/status/install/cancel commands; (4) setup dialog, controller/browser regressions; (5) fresh review/checks, commit/push.
