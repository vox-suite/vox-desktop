# Temporary meeting audio

User decision: local audio is temporary, retained for post-meeting transcription and crash recovery, then deleted after successful durable transcript persistence. Failed/cancelled transcription keeps audio for retry. No permanent audio retention option or cloud audio path is introduced.

Plan: (1) schema migration and durable cleanup intent guarded by the recording-file lock; verify every source has been transcribed and canonical WAV counts match before marking cleanup; (2) retryable directory cleanup after commit, automatically retried when opening the library, without rewriting notes/transcripts; (3) native ASR uses a single revision chain across sources and queues cleanup only after all source saves succeed; (4) expose audio availability/pending cleanup and a model-independent retry action; update UI copy; (5) regressions, fresh review, commit/push.

Ruling: keep the capture state and original frame counts for duration/quality evidence. Persist audio-deleted intent independently of capture state; never infer safe deletion from imported transcripts alone. The trusted native ASR pipeline owns the completion barrier. Preserve account ownership, OS locks, and CAS edits. Delete the managed recording directory (including temporary ASR JSON/logs) only after the durable barrier. This is ordinary file deletion, not forensic secure erasure or encryption. Existing recordings are not deleted just because transcripts already exist; they need a successful processing completion barrier.

Ledger: baseline a5cce62; clean tree. Cleanup is retried on library list/detail access after restart. Temporary audio remains plaintext until this cleanup; streaming-only transcription/encrypted temporary buffers are separate work.

Ledger: storage and processing/controller regressions observed failing before implementation, then green. Fresh review found an ASR revision-chain race after a postcommit detail read; a deterministic trigger regression reproduced old revision4 vs expected3. The strict ASR API now returns only its exact transaction revision, preserving the audio/newer edit when the barrier conflicts. Review recheck found no material remaining findings. Browser tests cover successful automatic removal and pending cleanup failures/retry without a model, preserving unsaved notes and saved transcript. No live capture or Windows device was used in this slice.
