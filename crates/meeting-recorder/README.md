# Shared local meeting recorder

The desktop and developer CLI use this single implementation for two-track flexaudio capture, checkpointed WAV writing, supervised cancellation, and local whisper.cpp transcription. The desktop executable dispatches capture-worker arguments before Tauri and single-instance initialization. Its inherited control pipe stops capture when its parent disappears; normal stop has a three-second grace before forced termination. Failed workers leave interrupted, recoverable meeting records.

The desktop owns one audio lease across Talk to Vox and meeting capture. Start is explicit, limited to two hours, and uses the default microphone/output. The global recording bar remains visible across pages and reports checkpointed seconds per source. Stop does not discard captured audio. Signing out cancels the job; an independent account watcher also cancels after account changes. Closing the window while a job is busy is prevented. Explicit quit cancels and waits up to ten seconds for cleanup; repeated quit requests share that wait.

The default setup now bundles a CPU speech runtime and installs verified model weights through **Set up local speech**. See `../meeting-models/README.md` for the installer contract and current evidence. After stopping, open the saved meeting and choose **Transcribe local audio**. Processing is local, cancellable, and source-separated. It holds an audio-file lock to exclude deletion/recovery, and a revision check rejects a concurrent edit/import rather than overwriting it. Successfully imported source text survives a failure on the other source; retry remains available. An advanced option still accepts a trusted local `whisper-cli` executable and compatible GGML model through native dialogs. The developer `tools/meeting-prototype/setup.py` path remains available.
Current limits: macOS 14.4+ for this capture backend; Windows still needs native hardware/packaged verification. No pause, device selection in the UI, tray/background mode, live ASR, AEC, VAD qualification, diarization, clock synchronization, summaries, tasks in this slice. Minimize behavior and signed-app permissions require device qualification. Audio is temporary and is deleted after both source transcripts are durably saved. Failed/cancelled processing retains it for retry; encrypted temporary storage remains outstanding. Managed capture and bundled ASR workers terminate on parent disconnection. The advanced external-engine path can still leave its separate ASR process running after an abrupt application crash; graceful quit is coordinated. No audio upload or cloud speech fallback is introduced.

## Temporary-audio follow-up

`processing::transcribe_meeting` is the shared completion path used by desktop transcription. It persists all source outputs before scheduling/removing audio, retains source files on failure/cancellation or a concurrent edit, and leaves durable retry intent if filesystem cleanup fails. See `../meeting-store/README.md` for crash ordering and schema migration. The developer CLI's standalone `record`/`transcribe` experiment still uses explicitly chosen developer output directories; it does not silently delete those independent developer fixtures.
