# Managed meeting speech model

The downloader accepts a local artifact directory and a cancellation flag, never an audio path, transcript, account token, or renderer-supplied URL. It fetches only the multilingual Whisper Base weights from the pinned Hugging Face revision `5359861c739e955e79d9a303bcbc70fb988958b1`: 147,951,465 bytes, SHA-256 `60ed5bc3dd14eea856493d334349b405782ddcaf0028d4b5df4088345fba2efe`.

An OS file lock excludes simultaneous installs. Valid installed weights are fully hashed and reused without network access. Downloads use a private temporary file, enforce the expected size while streaming, verify SHA-256, sync, and rename into the installed filename only after success. Cancel/failure closes outstanding filesystem operations before removing the temporary file, including on Windows. An abandoned partial from an abrupt process exit is discarded at the next explicit installation; range resumption is not implemented. The public download uses HTTPS and carries no Vox account credentials. Nine tests cover pinning, same-size corruption, publication, reuse, locking, cancellation, and stalled responses.

Desktop setup is explicit: **Set up local speech → Download local model**. The UI shows download bytes, verification, cancel/retry, and ready states. Weights are shared device resources and contain no personal meeting content. Logout cancels an active install; the installer also watches account changes. A downloaded engine executable, Python, CMake, or a C++ compiler is not required on the end user's device: the application bundles whisper-rs 0.16.0 / whisper-rs-sys 0.15.0 with its vendored whisper.cpp runtime. Native application builders need the native build prerequisites. `.cargo/config.toml` disables machine-specific CPU compilation; GPU acceleration is not enabled in this baseline. The existing external-engine chooser remains an advanced trusted-local-files option.

Managed inference runs in the desktop's disposable transcription worker, before Tauri startup. The worker has no network operation and exits on parent-pipe EOF; the parent bounds stop/timeout with the existing three-second supervisor grace. WAVs are validated and read in bounded 60-second chunks, with source-relative timestamps and no console transcript/debug output. Exact digital silence is skipped; this is not qualified VAD or a solution for all silence hallucinations. Chunk-boundary recognition, language switching, long-session accuracy, Windows packaging/device behavior, and GPU performance still require evaluation. Model integrity is checked before each managed transcription. UI readiness is cached, so external file corruption may leave a stale ready label until restart, while transcription safely refuses the modified weights.

## Verification on 2026-10-28

- A fresh real download through `cargo run -p vox-meeting-models --example install --locked -- /tmp/vox-meeting-managed-model-20261028` completed and passed size/SHA verification.
- `tests/meeting-embedded-smoke.py` ran the linked macOS desktop worker against those freshly installed weights and whisper.cpp's public JFK sample. The macOS sandbox denied network access; a separate socket probe confirmed the restriction. It produced one transcript segment in 1.77 seconds including startup/model load. This is a smoke test, not a meeting-quality or hardware benchmark.
- Closing the worker's parent pipe terminated it in 0.01 seconds without a transcript file. No capture device was opened.
- Browser fixtures verify explicit download consent, progress, background continuation, cancel/retry, verification gate, ready state, and narrow dialog layout. Existing recording/library suites also pass.
- This slice does not establish signed/notarized Mac permissions or Windows build/runtime support. The earlier Windows cross-check was blocked by the missing MinGW C compiler for bundled SQLite. Audio encryption/retention remains separate outstanding work; this installer does not change audio storage.
